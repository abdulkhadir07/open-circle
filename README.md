# OpenCircle

OpenCircle is a location-based social app where users discover temporary invite posts and persistent discussions without needing to follow each other.

## Tagline

Location-based invites and conversations without the follower system.

## Core Features

- User accounts with broad location: city, state/region, country
- Local and Global feeds
- Invite posts that expire after 24 hours
- Single and group invite posts
- Engagement request flow: pending, accepted, declined, held
- Chat room creation after accepted engagement
- Persistent banter/discussion posts
- User ratings after engagements
- Badge levels based on engagement count and positive ratings

## Tech Stack

- Backend: Java, Spring Boot
- Database: PostgreSQL
- Frontend: React
- Testing: JUnit, Mockito, Spring Boot Test
- CI/CD: GitHub Actions
- API Style: REST

## Project Goal

This project is built as a portfolio project to demonstrate full-stack development, REST API design, database modeling, testing, and CI/CD using Java Spring Boot, PostgreSQL, React, and GitHub Actions.
